# RollCal: every feature, and which plan gets it

Recommended plans (see docs/MONETIZATION.md for the reasoning). **(planned)** means it isn't built
yet; everything else is in the app today.

**How it works for guests:** an Event Pass, or a host on Plus, upgrades *that event for everyone in
it*. Guests never pay, and get the event's perks (full-size photos, longer videos, the video recap,
photos kept forever) while they're in it.

✓ = included · — = not included
